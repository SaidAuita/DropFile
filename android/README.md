# 📱 DropFile Mobile (Android)

Легковесное нативное Android-приложение для мгновенной отправки файлов (фото, видео, архивы, документы) со смартфона в папку обмена **FileBrowser** (`/Exchange/Mobile`) с последующей автоматической загрузкой на рабочий или домашний ПК через клиент **DropFile**.

---

## ✨ Возможности

- ⚡ **Мгновенная отправка из любого приложения (Share Sheet / Intent)**:
  - В Галерее, Проводнике, Telegram, WhatsApp или Камере нажмите **«Поделиться» → «DropFile»**.
  - Файлы сразу отправляются на сервер, а окно закрывается автоматически.
- 📥 **Импорт настроек в 1 клик**:
  - Никакого ручного ввода длинных URL и паролей на клавиатуре телефона.
  - Поддержка импорта готового файла `dropfile_mobile_config.json`.
- 🌐 **Поддержка прямого белого IP и HTTP/HTTPS**:
  - Включен `android:usesCleartextTraffic="true"`, поэтому приложение работает как по защищённому `https://`, так и по прямому `http://IP:PORT` без SSL.
- 📦 **Прямая установка по ссылке (APK)**:
  - Не требуется Google Play. Свежая версия собирается автоматически и доступна для скачивания в один клик.
- 🕒 **Журнал отправок**:
  - История последних 50 переданных файлов со статусами (Успешно / Ошибка), датой и размером.

## 🚀 Быстрый старт

### 1. Подготовка файла настроек на ПК
В папке десктопного DropFile на ПК выполните команду:
```bash
python export_mobile_config.py --url http://ВАШ_БЕЛЫЙ_IP:ПОРТ --folder /Exchange/Mobile
```
*(Если в вашем `config.json` на ПК уже прописан нужный внешний URL, можно запустить просто `python export_mobile_config.py`)*.

Утилита создаст файл `dropfile_mobile_config.json`:
```json
{
    "server_url": "http://123.45.67.89:8080",
    "username": "said",
    "password": "your_password",
    "target_folder": "/Exchange/Mobile",
    "auto_close": true
}
```

### 2. Установка приложения на телефон
1. Скачайте `DropFile-Mobile.apk` по ссылке из GitHub Releases:
   `https://github.com/SaidAuita/DropFile/releases/latest/download/DropFile-Mobile.apk`
   *(или скачайте артефакт из вкладки Actions вашего репозитория)*.
2. Откройте скачанный `.apk` на телефоне и подтвердите установку (разрешите установку из браузера/проводника).

### 3. Настройка приложения
1. Передайте `dropfile_mobile_config.json` на телефон (через Telegram «Избранное», шнур, почту или загрузите в веб-интерфейс FileBrowser).
2. Запустите **DropFile Mobile** на телефоне.
3. Перейдите в **«Настройки»** (иконка шестеренки в правом верхнем углу).
4. Нажмите **«📥 Импортировать файл настроек (.json)»** и укажите скачанный файл.
5. Приложение заполнит все поля и автоматически проверит связь с сервером!

## 📸 Как пользоваться быстрой отправкой

1. Откройте **Галерею**, выделите одно или несколько фото / видео.
2. Нажмите системную кнопку **«Поделиться»** (Share).
3. В появившемся списке выберите **DropFile**.
4. Появится компактное окно с индикатором загрузки:
   ```
   Отправка (1/3): IMG_20260922_124500.jpg [====>     ] 45%
   ```
5. После завершения окно закроется, а файлы сразу появятся на сервере в папке `/Exchange/Mobile` и скачаются на ваш ПК клиентом DropFile!
