# DropFile 📂

**Легковесный Dropbox-подобный клиент двусторонней синхронизации файлов для [FileBrowser](https://github.com/filebrowser/filebrowser) под Windows.**

## 💡 О проекте

[FileBrowser](https://github.com/filebrowser/filebrowser) — популярный веб-менеджер файлов для личных серверов, NAS, домашних мини-ПК и Docker. Однако у FileBrowser нет официального десктопного клиента, который автоматически синхронизировал бы локальную папку на компьютере по принципу Dropbox или OneDrive.

**DropFile** закрывает эту потребность:
- Работает в фоне без лишних окон (в системном трее Windows).
- Создает удобную папку обмена на Рабочем столе.
- Мгновенно выгружает добавленные локально файлы на сервер FileBrowser и скачивает удаленные изменения.
- Не требует WebDAV, SMB или сторонних облачных сервисов: обмен идет через стандартный **HTTPS/HTTP REST API** самого FileBrowser.
- Успешно работает через любые корпоративные фаерволы (порт 443), прокси (Nginx, Caddy, Traefik), туннели (Cloudflare Tunnel, Keenetic Cloud, Tailscale) или прямое подключение по белому/локальному IP.

## 🌟 Основные возможности

- 🔄 **Двусторонняя автоматическая синхронизация**:
  - Локальный мониторинг через `watchdog`: скопированный в папку файл мгновенно загружается на сервер.
  - Фоновый периодический опрос: новые или измененные файлы на сервере автоматически загружаются на ПК.
- 🛡️ **Защита от зацикливания и конфликтов**:
  - Временное подавление эхо-событий при скачивании с сервера.
  - Дебаунсинг локальных событий записи (ожидание завершения записи файла).
  - При одновременном изменении с двух компьютеров создается копия с пометкой `(Конфликт PC YYYY-MM-DD)`, предотвращая потерю данных.
- 🕒 **Информативный системный трей**:
  - 🟢 **Зеленый значок**: все файлы синхронизированы.
  - 🔄 **Синий значок**: выполняется передача данных.
  - 🔴 **Красный значок**: ошибка связи с сервером или неверная авторизация.
  - ⏸️ **Желтый значок**: синхронизация временно приостановлена.
- ⚙️ **Графический интерфейс настроек (GUI)**:
  - Кнопка быстрой проверки соединения с сервером («⚡ Проверить соединение»).
  - Выбор любой локальной папки и удаленного пути (по умолчанию `/DropFile`).
  - Создание ярлыка папки на Рабочем столе в один клик.
  - Настройка интервала опроса и фильтров исключений (`~$*`, `*.tmp` и т.д.).
  - Журнал последних действий (загрузки, скачивания, удаления, конфликты).
- 🚀 **Бесшумный автозапуск**:
  - Запуск через `DropFile.pyw` / `start_silent.vbs` без мерцающих окон командной строки.
  - Включение автозапуска при входе в Windows прямо из интерфейса настроек.

## 🚀 Быстрый старт

### 1. Требования
- Windows 10 / 11
- Python 3.10 или новее
- Работающий сервер [FileBrowser](https://github.com/filebrowser/filebrowser) с включенным доступом по HTTP или HTTPS

### 2. Установка

Клонируйте репозиторий или скачайте архив:
```bash
git clone https://github.com/SaidAuita/DropFile.git
cd DropFile
```

Установите необходимые Python-библиотеки:
```bash
pip install -r requirements.txt
```

### 3. Запуск и настройка

1. Запустите `DropFile.pyw` (или дважды щелкните по `run.bat`).
2. При первом запуске автоматически откроется окно настроек:
   - **Адрес сервера**: URL вашего сервера FileBrowser (например, `https://files.yourdomain.com` или `http://10.0.0.10:8080`).
   - **Имя пользователя** и **Пароль**: логин и пароль в FileBrowser.
   - **Локальная папка**: папка на компьютере (по умолчанию создается `Рабочий стол\DropFile`).
   - **Удаленная папка**: папка в FileBrowser (по умолчанию `/DropFile`, создается автоматически).
3. Нажмите кнопку **«⚡ Проверить соединение»**.
4. После успешной проверки нажмите **«Сохранить и применить»**.
5. Всё готово! В трее (рядом с часами) появится иконка со статусом, а на Рабочем столе — папка для обмена.

## 🐳 Развертывание сервера FileBrowser (Docker)

Если у вас еще не развернут FileBrowser, его можно запустить на домашнем сервере, VPS или NAS одной командой Docker:

```bash
docker run -d \
  --name filebrowser \
  -v /data/files:/srv \
  -v /data/filebrowser.db:/database/filebrowser.db \
  -v /data/settings.json:/.filebrowser.json \
  -p 8080:80 \
  --restart unless-stopped \
  filebrowser/filebrowser:latest
```

*По умолчанию логин: `admin`, пароль: `admin` (смените при первом входе в веб-интерфейс).*

## 📁 Структура проекта

```text
DropFile/
├── DropFile.pyw         # Главная точка входа (запуск без открытия консоли)
├── config.py            # Менеджер конфигурации (поддержка config.json и %APPDATA%)
├── config.example.json  # Шаблон файла конфигурации
├── fb_client.py         # REST API клиент к FileBrowser (JWT авторизация, чтение, загрузка)
├── sync_engine.py       # Движок двусторонней синхронизации и защиты от эхо
├── state_db.py          # SQLite база данных (state.db) для учета хешей и журнала
├── gui_settings.py      # Графический интерфейс настроек и журнала на Tkinter
├── tray.py              # Иконка в системном трее и контекстное меню (pystray)
├── icons.py             # Динамическая генерация четких иконок статуса (Pillow)
├── win_utils.py         # Интеграция с Windows (автозапуск в реестре, ярлыки)
├── run.bat              # Батник для быстрого старта
├── start_silent.vbs     # VBS-скрипт для скрытого запуска
├── requirements.txt     # Зависимости проекта
├── LICENSE              # Лицензия MIT
└── tests/               # Набор модульных тестов
    ├── test_fb_client.py
    ├── test_state_db.py
    └── test_sync_engine.py
```
