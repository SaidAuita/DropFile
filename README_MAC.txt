==================================================================
                 DropFile для macOS (Инструкция)
==================================================================

1. УСТАНОВКА (Рекомендуется):
   - Дважды кликните по файлу "Install.command".
   - Скрипт проверит окружение, установит зависимости и создаст
     ярлык "DropFile" в ваших Программах и на Рабочем столе.

2. БЫСТРЫЙ ЗАПУСК БЕЗ УСТАНОВКИ:
   - Дважды кликните по файлу "Run.command" (или запустите DropFile.pyw).

3. ЕСЛИ MACOS БЛОКИРУЕТ ЗАПУСК ("Не удается открыть"):
   - Нажмите правой кнопкой мыши (или Control + клик) по "Install.command" 
     и выберите "Открыть" -> затем подтвердите "Открыть".
   - Или в Терминале в этой папке выполните:
     chmod +x *.command && xattr -cr .

После запуска иконка DropFile появится в верхней строке меню (возле часов).
