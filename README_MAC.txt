==================================================================
                 DropFile для macOS (Инструкция)
==================================================================

1. УСТАНОВКА (Рекомендуется для всех Mac):
   - Дважды кликните по файлу "Install.command".
   - Скрипт проверит окружение Python 3, установит зависимости в .venv
     и настроит приложение "DropFile" в /Applications и на Рабочем столе.

2. ДЛЯ INTEL MAC / HACKINTOSH (x230, macOS 10.15 Catalina / Big Sur / Monterey):
   - Официальный бинарник в GitHub Releases (DropFile-macOS.zip) собирается
     на раннерах GitHub Actions для Apple Silicon (ARM64, macOS 14+).
     На процессорах Intel x86_64 он не запустится («Несовместимый тип ЦП / Bad CPU type»).
   - Для Intel Mac создается нативная версия в 2 клика:
     1) Дважды кликните "Install.command" (или ./install_mac.command в Терминале).
     2) Дважды кликните "build_mac.command" (или ./build_mac.command в Терминале).
     -> Будет скомпилирован нативный /Applications/DropFile.app под ваш Intel Mac.
   - Скачать архив с исходным кодом новой версии всегда можно:
     - Из окна настроек DropFile кнопкой «📦 Скачать исходники (.zip)».
     - Либо со страницы GitHub Releases: архив Source code (.zip).
   - Встроенный автоапдейтер DropFile на Intel Mac автоматически распознает
     архитектуру и безопасно скачивает исходники вместо чужого ARM64 бинарника.

3. БЫСТРЫЙ ЗАПУСК БЕЗ УСТАНОВКИ:
   - Дважды кликните по файлу "Run.command" (или запустите DropFile.pyw).

4. ЕСЛИ MACOS БЛОКИРУЕТ ЗАПУСК ("Не удается открыть"):
   - Нажмите правой кнопкой мыши (или Control + клик) по "Install.command" 
     и выберите "Открыть" -> затем подтвердите "Открыть".
   - Или в Терминале в этой папке выполните:
     chmod +x *.command && xattr -cr .

После запуска иконка DropFile появится в верхней строке меню (возле часов).
