# 📁 DropFile — Примеры конфигурации и руководство по развертыванию

Данная папка содержит типовые примеры файла `config.json` для быстрого развертывания клиента **DropFile** на рабочих станциях пользователей.

---

## 🚀 Способы настройки клиента у пользователя

### Способ 1. Портативное развертывание в 1 клик (Zero-Setup для пользователя)
1. Скопируйте файл `config.json` из папки `examples/portable_setup/` в одну папку с `DropFile.exe`.
2. Отредактируйте параметры под вашу сеть (например, IP-адрес сервера или путь к диску `Z:`).
3. Разместите эту папку в общем сетевом доступе или отправьте пользователю.
4. **Пользователю достаточно запустить `DropFile.exe`** — программа автоматически запустится в портативном режиме, подхватит все настройки и сразу начнет работу без дополнительных вопросов.

### Способ 2. Экспорт / Импорт настроек через графический интерфейс
1. Настройте DropFile один раз на компьютере администратора.
2. В окне настроек перейдите на вкладку **«Настройки»** ➔ нажмите кнопку **«Экспорт настроек»** (сохранится файл `dropfile_config_backup.json`).
3. На компьютере пользователя откройте настройки DropFile и нажмите **«Импорт настроек»**. Все серверы, папки и параметры синхронизации будут применены мгновенно.

### Способ 3. Ручная настройка через GUI (Если не сработало автоопределение)
Если кнопка **«Автоопределение»** во вкладке «Папки» не смогла обнаружить сервер (например, из-за блокировки сетевого сканирования фаерволом или нахождения в разных подсетях/VLAN):
1. Перейдите во вкладку **«Папки» (Folders)**.
2. В строке **«Сервер LAN / SMB»** вручную введите IP-адрес или сетевое имя сервера (например, `192.168.1.100` или `nas.local`).
3. Строка сетевого пути автоматически обновится на `\\192.168.1.100\Exchange`.
4. Нажмите кнопку **«Подключить диск»** (для назначения буквы `Z:`) или **«Создать ярлык»**.
5. Либо нажмите кнопку **«Обзор»** у поля папки Exchange и выберите любую уже подключенную сетевую или локальную папку.

## ⚙️ Описание параметров `config.json`

| Параметр | Тип | Описание | Пример значения |
| :--- | :---: | :--- | :--- |
| `server_url` | `str` | URL основного сервера FileBrowser (REST API) | `"http://192.168.1.100:8080"` |
| `username` | `str` | Имя пользователя учетной записи FileBrowser | `"employee"` |
| `password` | `str` | Пароль учетной записи FileBrowser | `"Password123!"` |
| `exchange_path` | `str` | Путь к общей папке обмена DropSync (диск или UNC-путь) | `"Z:\\"` или `"\\\\192.168.1.100\\Exchange"` |
| `output_path` | `str` | Локальная папка публикации готовых файлов для клиентов | `"C:\\Users\\User\\Desktop\\Output"` (или пусто = дефолт) |
| `output_remote_path` | `str` | Удаленная папка на сервере FileBrowser для раздачи ссылок | `"/Output"` |
| `auto_copy_share_link`| `bool`| Автоматически создавать и копировать публичную ссылку на файл в трее | `true` |
| `speed_monitor_mode` | `str` | Режим монитора скорости (`"server"` — DropSync сервер, `"client"` — ПК) | `"server"` |
| `language` | `str` | Язык интерфейса (`"ru"`, `"en"`, `"de"`, `"fr"`, `"es"`, `"it"`, `"pt"`, `"pl"`, `"zh"`, `"ja"`) | `"ru"` |
| `poll_interval` | `int` | Интервал проверки удаленных изменений (в секундах) | `30` |
| `start_with_windows` | `bool`| Автозагрузка программы при старте операционной системы | `false` (или `true`) |
| `notify_on_sync` | `bool`| Показывать всплывающие уведомления Windows при синхронизации | `true` |
| `backup_server_enabled`| `bool`| Включить поддержку второго резервного сервера | `false` (или `true`) |
| `backup_server_url` | `str` | URL резервного сервера FileBrowser | `"http://192.168.1.101:8080"` |
| `sync_backup_server` | `bool`| Двустороннее зеркалирование между Сервером 1 и Сервером 2 | `false` |
| `file_retention_days`| `int` | Автоочистка файлов старше N дней (0 = выключено) | `30` |
| `conflict_action` | `str` | Действие при конфликте одновременного редактирования (`"keep_both"`) | `"keep_both"` |
