## 1. Системные требования
* **Операционная система**: macOS 10.15 Catalina или новее (включая виртуальные машины Tahoe / Sequoia и Хакинтош).
* **Архитектура процессора**: Intel Core (x86_64) или Apple Silicon (M1 / M2 / M3 / M4).
* **Окружение**: Python 3.9 – 3.12 (с поддержкой Tkinter).
* **Серверная часть**: Работающий экземпляр [FileBrowser](https://github.com/filebrowser/filebrowser) (HTTP или HTTPS).

## Способ 1. Простая установка в 1 клик (Рекомендуется для всех)

Этот способ займет меньше 1 минуты и не требует специальных знаний.

### Шаг 1. Загрузка и правильное размещение папки
1. Скачайте репозиторий:
   - Через браузер: зеленая кнопка **Code** ➔ **Download ZIP** на странице [https://github.com/SaidAuita/DropFile](https://github.com/SaidAuita/DropFile).
   - Либо через Терминал: `git clone https://github.com/SaidAuita/DropFile.git ~/DropFile`
2. **ВАЖНО: куда положить распакованную папку:**
   - Откройте Finder и нажмите сочетание клавиш **`Cmd + Shift + H`** — откроется ваша **домашняя папка** (`/Users/<ваше_имя>/`).
   - Перетащите распакованную папку прямо туда и назовите её **`DropFile`** (получится путь `~/DropFile`).
   > [!IMPORTANT]
   > **Не помещайте папку в «Документы» (`~/Documents`)!**  
   > В macOS Catalina и новее папка «Документы» защищена системной политикой Apple (TCC), которая блокирует запуск скриптов ошибкой `Operation not permitted`. В домашней папке (`~/DropFile`) таких ограничений нет!

### Шаг 2. Запуск инсталлятора
1. Зайдите в папку `~/DropFile`.
2. Нажмите **правой кнопкой мыши** (или двумя пальцами по тачпаду) на файле **`install_mac.command`** ➔ выберите **«Открыть в программе» (Open With)** ➔ **«Терминал» (Terminal)**  
   *(или зажмите клавишу `Control`, кликните по файлу и нажмите «Открыть»)*.
3. Откроется окно Терминала, и инсталлятор автоматически сделает всё за вас:
   - Проверит наличие Python 3.
   - Создаст изолированное виртуальное окружение `.venv`.
   - Установит все необходимые библиотеки (`requests`, `pystray`, `watchdog`, `pillow`, `pyobjc`).
   - Соберёт приложение `DropFile.app` в общей системной папке `/Applications/` (папка «Программы»).
   - Создаст удобный ярлык на Рабочем столе для синхронизации.
4. В конце появится вопрос: `Launch DropFile right now? [Y/n]`. Нажмите клавишу **`Y`** (или `Enter`).
5. **Всё готово!** Окно Терминала после этого можно **просто закрыть** — клиент DropFile уже работает в фоновом режиме в верхней строке меню (menu bar).

## Способ 2. Сборка автономного нативного приложения DropFile.app

Если вы хотите получить **100% нативное автономное приложение**, которое:
* Не требует держать открытым Терминал;
* Не показывает иконку Python в Dock;
* Не зависит от папки с исходным кодом (папку с исходниками после сборки можно удалить или заархивировать);
* Содержит внутри свой собственный автономный Python и все библиотеки;

### Инструкция по сборке:
1. Зайдите в папку `~/DropFile`.
2. Запустите скрипт **`build_mac.command`** (двойным кликом или в Терминале: `python3 build_mac.py`).
3. Скрипт автоматически запустит сборщик PyInstaller и создаст:
   - **`dist/DropFile.app`** — полноценное приложение macOS;
   - **`dist/DropFile-macOS.zip`** — готовый переносимый архив для передачи на другие компьютеры Mac.
4. По завершении скрипт предложит выбор места установки:
   - **`1` (по умолчанию)**: общая системная папка **`/Applications/DropFile.app`** (рекомендуется);
   - **`2`**: пользовательская папка **`~/Applications/DropFile.app`**.
   Просто нажмите `Enter` (выберется пункт 1). При необходимости подтвердите установку в системные программы паролем администратора.
5. Приложение скопируется в папку «Программы» и зарегистрируется в LaunchServices.
6. Теперь вы можете запускать DropFile прямо из Spotlight (`Cmd + Пробел` ➔ DropFile), Launchpad или Finder. Приложение запускается бесшумно, аккуратно добавляя значок облака в строку меню рядом с часами!

## Шаг 1. Проверка и установка Python 3

Если при установке инсталлятор сообщил, что Python 3 не найден:

### Быстрая установка в 1 команду через Терминал (Рекомендуется ⭐)
Выполните в Терминале следующую строку:

```bash
curl -O https://www.python.org/ftp/python/3.11.9/python-3.11.9-macos11.pkg && sudo installer -pkg python-3.11.9-macos11.pkg -target / && "/Applications/Python 3.11/Install Certificates.command" && rm python-3.11.9-macos11.pkg
```
> Потребуется ввести пароль администратора Mac. После завершения вернитесь к запуску `install_mac.command`.

## Первоначальная настройка подключения

После запуска в верхнем меню macOS (рядом с часами и Wi-Fi) появится иконка облака DropFile:

1. Нажмите на иконку и выберите **«Параметры» (Settings)**.
2. Во вкладке **🌐 Подключение**:
   - **Адрес сервера (Server URL)**: адрес вашего FileBrowser (например, `https://files.example.com` или `http://192.168.1.50:8080`).
   - **Логин** и **Пароль**: учетная запись пользователя FileBrowser.
   - Нажмите кнопку **«⚡ Проверить соединение»** для проверки связи.
3. Во вкладке **📁 Папки**:
   - **Локальная папка**: каталог на вашем Mac (по умолчанию `~/Desktop/DropFile_Sync`).
   - **Папка на сервере**: директория в FileBrowser (по умолчанию `/DropFile`).
4. Во вкладке **⚙️ Параметры**:
   - Выберите язык интерфейса (доступно 10 языков, включая русский).
   - Включите **«Автозапуск»**, чтобы DropFile стартовал при входе в систему macOS.
5. Нажмите кнопку **«Сохранить и применить»**. DropFile мгновенно начнет двустороннюю синхронизацию!

## Полезные функции и сценарии работы

* **📥 Получение недостающих файлов в 1 клик**: Если вы только что подключили Mac, или на сервере уже были загружены файлы и папки другими пользователями — нажмите **«📥 Получить недостающие файлы»** (кнопка во вкладке «📁 Папки» настроек или в меню-баре). Клиент мгновенно просканирует сервер, создаст все подпапки и аккуратно загрузит все отсутствующие локально файлы.
* **📁 Полная синхронизация структуры папок**: любые созданные каталоги (включая пустые папки) автоматически воспроизводятся между Mac, сервером и Windows.
* **🔗 Быстрый шеринг ссылок**: при загрузке любого файла в меню-баре активируется пункт `Скопировать ссылку на <файл>`. Кликните по нему — готовая публичная ссылка скопируется в буфер обмена (`pbcopy`) для отправки коллегам.
* **🛡️ Умная защита от конфликтов (SHA-256)**: файлы с одинаковым содержимым никогда не создают дубликатов `(Conflict ...)`, даже если отличаются даты изменения.
* **🧹 Дедупликация в 1 клик**: кнопка `🔍 Удалить дубликаты` в Настройках быстро находит и удаляет лишние копии с совпадающим хэшем.

## Часто задаваемые вопросы и устранение неполадок (FAQ)

### 1. Почему после установки остался открыт Терминал?
Когда вы запускаете `.command` файлы через Finder, macOS открывает для них окно Терминала. После того, как инсталлятор сообщил «Done», приложение DropFile уже работает в фоновом режиме. Окно Терминала можно **спокойно закрыть**.

### 2. Почему в Dock появлялась иконка Python?
В скриптовом режиме macOS по умолчанию отображает иконку интерпретатора Python. Начиная с версии 1.08, мы добавили политику `NSApplicationActivationPolicyAccessory`, которая автоматически скрывает иконку Python из Dock. А при сборке нативного пакета `DropFile.app` (через `build_mac.command`) приложение полностью избавлено от любых следов Python.

### 3. Ошибка «Operation not permitted» при запуске?
Это означает, что папка проекта была помещена в защищённую директорию macOS (например, «Документы» `~/Documents`). Переместите папку `DropFile` в корень домашней папки (`/Users/<ваше_имя>/DropFile`) — там ограничений нет.

### 4. Ошибка LaunchServices error -10810?
Эта ошибка возникала в старых версиях из-за разыменования путей виртуального окружения. В текущей версии она устранена. Если вы запускаете приложение вручную, убедитесь, что карантин снят:
```bash
xattr -cr /Applications/DropFile.app 2>/dev/null || xattr -cr ~/Applications/DropFile.app 2>/dev/null
```

### 5. Как полностью удалить DropFile с Mac?
Удалите три папки:
```bash
rm -rf /Applications/DropFile.app ~/Applications/DropFile.app
rm -rf ~/Library/Application\ Support/DropFile
rm -f ~/Library/LaunchAgents/com.saidauita.dropfile.plist
```
