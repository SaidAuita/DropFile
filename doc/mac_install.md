## 1. Системные требования
* **Операционная система**: macOS 10.15 Catalina или новее (включая виртуальные машины Tahoe / Sequoia и Хакинтош).
* **Архитектура процессора**: Intel Core (x86_64) или Apple Silicon (M1 / M2 / M3 / M4).
* **Окружение**: Python 3.9 – 3.12 (с поддержкой Tkinter и Tcl/Tk).
* **Серверная часть**: Работающий экземпляр [FileBrowser](https://github.com/filebrowser/filebrowser) (HTTP или HTTPS).

## Шаг 1. Проверка и установка Python 3

Откройте **Терминал** (`Terminal.app` — находится в папке *Программы* ➔ *Утилиты* или через поиск Spotlight `Cmd + Пробел`).

### 1.1. Проверка наличия Python 3 и Tkinter

Выполните команды в Терминале:

```bash
# 1. Проверка версии Python 3:
python3 --version

# 2. Проверка пути к интерпретатору:
which python3

# 3. Проверка графического движка Tkinter (нужен для окна Настроек):
python3 -m tkinter
```

* **Если отобразилась версия** (например, `Python 3.9.x`, `Python 3.11.x` или новее) и при выполнении `python3 -m tkinter` открылось небольшое тестовое окно с кнопками — **всё в порядке**, переходите к **Шагу 2**.
* **Если появилось сообщение `command not found`** или ошибка `No module named _tkinter` (характерно для чистых систем macOS 10.15 Catalina или чистых виртуалках Tahoe) — установите Python 3 одним из способов ниже.

---

### 1.2. Установка Python 3 через Терминал

Выберите наиболее удобный способ:

#### Способ 1. Быстрая установка официального Python в 1 команду (Рекомендуется ⭐)
*Скачивает и устанавливает официальный универсальный пакет Python 3.11 с python.org (Universal2 для Intel и Apple Silicon) с встроенным Tcl/Tk (Tkinter) прямо через консоль, без открытия браузера:*

```bash
# 1. Скачиваем официальный инсталлятор
curl -O https://www.python.org/ftp/python/3.11.9/python-3.11.9-macos11.pkg

# 2. Устанавливаем в систему (потребуется ввести пароль администратора Mac)
sudo installer -pkg python-3.11.9-macos11.pkg -target /

# 3. Устанавливаем системные SSL-сертификаты для Python (нужно для HTTPS)
"/Applications/Python 3.11/Install Certificates.command"

# 4. Удаляем временный установочный файл
rm python-3.11.9-macos11.pkg
```

#### Способ 2. Установка через инструменты Apple (Command Line Tools)
*Штатная команда macOS, которая ставит `python3`, `git` и базовые утилиты:*

```bash
xcode-select --install
```
> Появится системное диалоговое окно — нажмите **«Установить»** (Install) и дождитесь окончания загрузки.

#### Способ 3. Через менеджер пакетов Homebrew
*Если на вашем Mac используется Homebrew:*

```bash
brew install python python-tk
```

> [!TIP]
> **Если Homebrew еще не установлен, его можно поставить командой:**
> ```bash
> /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
> brew install python python-tk
> ```

## Шаг 2. Загрузка исходных файлов

Файлы для macOS доступны как в основной ветке репозитория, так и в отдельной ветке `macos`.

### Вариант 1. Через Терминал с помощью Git (Рекомендуется)
```bash
cd ~
git clone https://github.com/SaidAuita/DropFile.git
cd DropFile
```
*(Также можно явно указать ветку `macos`: `git clone -b macos https://github.com/SaidAuita/DropFile.git`)*

### Вариант 2. Через браузер в виде ZIP-архива
1. Перейдите по ссылке на репозиторий: [https://github.com/SaidAuita/DropFile](https://github.com/SaidAuita/DropFile) (или [ветка macos](https://github.com/SaidAuita/DropFile/tree/macos)).
2. Нажмите зеленую кнопку **Code** ➔ **Download ZIP**.
3. Распакуйте скачанный архив в вашу домашнюю папку (например, `~/DropFile`).

## Шаг 3. Автоматическая установка в 1 клик (`install_mac.command`)

В папке проекта подготовлен нативный командный файл `install_mac.command`:

1. Откройте папку `DropFile` в Finder:
   ```bash
   open ~/DropFile
   ```
2. Дважды кликните по файлу **`install_mac.command`**.
3. Откроется окно Терминала, в котором скрипт автоматически выполнит всё за вас:
   - Создаст изолированное виртуальное окружение `.venv` (чтобы не затрагивать системный Python).
   - Установит зависимости (`requests`, `pystray`, `watchdog`, `pillow`, `pyobjc` для поддержки Cocoa/AppKit).
   - Соберет нативное приложение **`~/Applications/DropFile.app`** со свойством `LSUIElement=1` (приложение работает как агент в Menu Bar около часов без лишней иконки в Dock).
   - Создаст ярлык папки синхронизации на Рабочем столе: `~/Desktop/DropFile`.
4. В конце появится вопрос: `Запустить DropFile прямо сейчас? [Y/n]`. Нажмите `Enter` или `Y`.

> [!TIP]
> **Если macOS блокирует запуск скрипта (Gatekeeper):**
> Зажмите клавишу `Control` (или нажмите правой кнопкой мыши) на файле `install_mac.command` и выберите **«Открыть» (Open)**, затем подтвердите открытие.  
> Либо выполните в Терминале команду снятия карантина:
> ```bash
> xattr -cr ~/DropFile
> ```

## Шаг 4. Первоначальная настройка подключения

После запуска в верхнем меню macOS (рядом с часами и Wi-Fi) появится иконка облака DropFile:

1. Нажмите на иконку и выберите **«Параметры» (Settings)**.
2. Во вкладке **🌐 Подключение**:
   - **Адрес сервера (Server URL)**: адрес вашего FileBrowser (например, `https://files.example.com` или `http://192.168.1.50:8080`).
   - **Логин** и **Пароль**: учетная запись пользователя FileBrowser.
   - Нажмите кнопку **«⚡ Проверить соединение»** для проверки связи.
3. Во вкладке **📁 Папки**:
   - **Локальная папка**: каталог на вашем Mac (по умолчанию `~/Desktop/DropFile`).
   - **Папка на сервере**: директория в FileBrowser (по умолчанию `/DropFile`).
4. Во вкладке **⚙️ Параметры**:
   - Выберите язык интерфейса (доступно 10 языков, включая русский).
   - Отметьте чекбокс **«Создавать ярлык на рабочем столе при запуске»** по желанию.
   - Включите **«Автозапуск»**, чтобы DropFile стартовал при входе в систему macOS.
5. Нажмите кнопку **«Сохранить и применить»**. DropFile мгновенно начнет двустороннюю синхронизацию!

## Шаг 5. Полезные функции и сценарии работы

* **🔗 Быстрый шеринг ссылок**: при загрузке любого файла в меню-баре активируется пункт `Скопировать ссылку на <файл>`. Кликните по нему — готовая публичная ссылка скопируется в буфер обмена (`pbcopy`) для отправки коллегам.
* **🛡️ Умная защита от конфликтов (SHA-256)**: файлы с одинаковым содержимым никогда не создают дубликатов `(Conflict ...)`, даже если отличаются даты изменения.
* **🧹 Дедупликация в 1 клик**: кнопка `🔍 Удалить дубликаты` в Настройках быстро находит и удаляет лишние копии с совпадающим хэшем.
* **💻 Портативный запуск без установки**: если не хотите устанавливать приложение в `~/Applications`, просто дважды кликните по `run_mac.command`.

## Часто задаваемые вопросы и устранение неполадок (FAQ)

### 1. Где хранятся настройки и база данных на Mac?
По стандартам Apple конфигурация и локальная база SQLite хранятся в папке пользователя:  
`~/Library/Application Support/DropFile/`  
(`config.json` и `state.db`).

### 2. При двойном клике по .command пишет «Permission denied»?
Назначьте права на запуск в Терминале:
```bash
chmod +x ~/DropFile/*.command
```

### 3. Как настроить автозапуск вручную?
При включении галочки автозапуска DropFile автоматически создает файл агента `launchd`:  
`~/Library/LaunchAgents/com.saidauita.dropfile.plist`  
Запуск и остановка контролируются стандартной системной утилитой:
```bash
launchctl load ~/Library/LaunchAgents/com.saidauita.dropfile.plist
launchctl unload ~/Library/LaunchAgents/com.saidauita.dropfile.plist
```

### 4. Как полностью удалить DropFile с Mac?
Удалите три папки/файла:
```bash
rm -rf ~/Applications/DropFile.app
rm -rf ~/Library/Application\ Support/DropFile
rm -f ~/Library/LaunchAgents/com.saidauita.dropfile.plist
```
